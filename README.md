# Banana Slides

Trình tạo bài thuyết trình AI gốc - Vibe your slides like vibe coding.

## Giới thiệu

Banana Slides là ứng dụng tạo slide bài thuyết trình thông minh được xây dựng trên nền tảng trí tuệ nhân tạo hiện đại. Ứng dụng hỗ trợ chuyển đổi từ ý tưởng, dàn ý hoặc tài liệu PDF/PPTX thành bài thuyết trình hoàn chỉnh với hình ảnh và nội dung chất lượng cao.

## Tính năng chính

- **Tạo một chạm**: Chỉ cần một câu ý tưởng hoặc dàn ý đơn giản để tạo toàn bộ bài thuyết trình.
- **Chỉnh sửa bằng ngôn ngữ tự nhiên**: Trò chuyện với AI để chỉnh sửa văn bản, phong cách hoặc thay thế hình ảnh.
- **Chỉnh sửa theo vùng**: Khoanh vùng bất kỳ khu vực nào trên slide để vẽ lại hoặc tinh chỉnh chi tiết.
- **Xuất đa định dạng**: Hỗ trợ xuất ra PowerPoint (.pptx có thể chỉnh sửa văn bản), PDF chất lượng cao, hình ảnh và video thuyết minh MP4.
- **Mẫu phong cách phong phú**: Thư viện phong cách đa dạng từ tối giản, công nghệ kính mờ, đến báo cáo học thuật chuyên sâu.

## Cài đặt và chạy

### Yêu cầu
- Python >= 3.10
- Node.js >= 18
- uv (khuyến nghị cho quản lý package Python)

### Khởi động nhanh
```bash
# Cài đặt và chạy backend
cd backend
python app.py

# Cài đặt và chạy frontend
cd frontend
npm install
npm run dev
```

Truy cập giao diện tại: `http://localhost:3011` (hoặc cổng hiển thị trong terminal).
