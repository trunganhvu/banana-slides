{"job_id":"job-1","job_type":"full_generation","creation_type":"idea","idea_prompt":"","language":"zh","export":{"formats":["pptx"]}}

| `idea_prompt` | * | creation_type=idea  |
| `language` |  | `zh``en``ja``auto` |
| `use_template` |  |  `true` |

# Config

```bash
banana-cli run jobs \
  --file jobs.jsonl \
  --report report.json \
  --continue-on-error \
  --timeout-sec 3600 \
  --state-file state.json \
  --done-marker-file done.json
```

- `--state-file`
- `--done-marker-file` job
- `--continue-on-error` / `--fail-fast`
